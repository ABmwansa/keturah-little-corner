# Umodzi Medical Center Website

A responsive React and Vite website for Umodzi Medical Center in Lusaka, Zambia.

## Run locally

```bash
npm install
npm run dev
```

## Clinic content

Update clinic contact details, services, mission, vision, and the WhatsApp number in `src/data/clinicContent.js`.

Add the confirmed clinic email to the `email` field before publishing.

## Build and deploy

```bash
npm run build
```

Upload the resulting `dist` folder to the chosen hosting provider.
